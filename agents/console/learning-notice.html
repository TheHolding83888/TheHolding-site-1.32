Learning & safety.

The Holding can use conversations as a carefully bounded learning signal. It does not let public messages directly change verified facts, code, methodology, security rules, wallets or capital.

Checking whether conversation learning is enabled…

What may be learned

Only when a visitor explicitly opts in, the system may keep a privacy-filtered question sample, the answer outcome, source label and optional helpful / not-helpful feedback. The purpose is to find repeated questions, missing knowledge, unclear explanations and answers that need review.

What is not kept

  • Raw unfiltered conversation text is not stored by the learning intake.
  • Answer text is not stored; only a hash and source/outcome metadata are kept.
  • Seed phrases, private keys, passwords, tokens and detected high-risk messages are excluded from learning samples.
  • Emails, phone numbers, URLs and wallet-like identifiers are redacted from stored samples.
  • The application does not intentionally store raw IP addresses. A short-lived pseudonymous anti-abuse bucket may be used for rate limiting.

Retention and control

Sanitized learning events are designed for a rolling 30-day retention window. Detailed samples are available only through an authenticated operator endpoint. Public users cannot turn their text into trusted project memory or system instructions.

Conversation learning is fail-closed: it remains disabled unless the operator has explicitly enabled it and configured the required controller identity, contact and legal-basis notice.

Financial, legal and security boundaries

The console is informational and educational. It can show verified measurements, explain mechanisms, compare factual data and discuss risks. It does not provide personalized buy/sell/allocation recommendations, individualized legal advice or individualized tax advice.

Never paste a seed phrase, private key, password, API key or other secret into the console. Public input is treated as untrusted data, never as authority over tools or system rules.

Operator information

When learning is enabled, the current controller information and declared legal basis are exposed by the same-origin learning-status endpoint and shown below.

Controller: Not enabled / not configured

Declared legal basis / notice: Not enabled / not configured
