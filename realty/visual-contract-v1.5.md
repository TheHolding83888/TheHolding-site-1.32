# Realty v1.5 Visual Acceptance Contract

Owner-approved visual references received 2026-08-30 define the v1.5 shell target.

## Dark mode
- immersive terminal composition
- premium black/charcoal base
- warm restrained gold for Physical World
- restrained violet/deep blue for Digital World
- strong visual hero, market-density feel, world gateways, rich cards
- side/navigation depth without losing clarity
- data-heavy but premium, not generic trading-dashboard noise

## Light mode
- editorial luxury direction
- warm white canvas, fine borders, large serif display typography
- image-led Real-World / Virtual Realty gateways
- elegant market chooser, listings, intelligence preview and footer
- mobile is a first-class layout, not a collapsed desktop afterthought

## Shared contract
- preserve real source-backed data and existing Realty depth
- no fake global KPIs from old concept mocks
- unknown remains unknown
- dark/light theme toggle must be obvious and persistent
- cards and primary navigation must remain fully clickable
- performance is part of acceptance: avoid unnecessary payloads and blocking assets
- desktop and mobile must both feel intentional and premium
