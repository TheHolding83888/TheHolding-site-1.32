# PRIVATE PATHS: /yield-admin is disallowed above. Confirm the exact live
# URL — if the admin view sits elsewhere, update these lines. robots.txt
# only asks crawlers not to index; it does NOT secure a page. Anything
# genuinely sensitive needs authentication or an X-Robots-Tag: noindex
# header, since the file itself is public and lists the path.
#
# CLOUDFLARE: this site sits behind Cloudflare. robots.txt is an honour
# system — verify no WAF/CDN rule (e.g. the one-click "Block AI Bots")
# is silently overriding these directives, or AI crawlers are blocked
# regardless of what this file says.
#
# CRAWL-DELAY: ignored by Googlebot; respected by Bing, Yandex and others.
#
# UNLISTED BOTS: the wildcard group allows everything not named here, so
# new AI crawlers gain access automatically. Only the block list needs
# active maintenance.
#
# DUPLICATE URLS: if pages are reachable both as /companies and
# /companies.html, rely on the canonical tags already in place rather than
# blocking .html here — a blanket block would deindex the real pages.
