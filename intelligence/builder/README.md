# The Holding Self-Improvement Builder Sandbox v0.1

This layer converts only owner-approved Proposal items into bounded candidate work packets.

It is intentionally **not a code-writing executor**. v0.1 cannot edit production files, create branches or pull requests, merge, release, sign, transact, touch wallets, or execute capital.

The candidate queue exists to make the next step explicit and reviewable:

`APPROVED Proposal → Candidate packet → Independent Builder Review → future Guardian-gated sandbox build`

Each candidate carries exact Proposal and Decision Memory provenance, a bounded objective, allowed and forbidden scope, required evidence, a verification plan, and a reversibility statement.

For security research candidates, v0.1 performs planning only:
- third-party script findings → trust/SRI/self-hosting/removal/CSP research plan;
- `innerHTML` findings → sink inventory + provenance classification plan.

Actual repository patch generation belongs to a later Builder phase after the Guardian capability gate is installed and proven.
